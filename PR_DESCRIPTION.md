# PR: P06 - Secure Coding

## Описание

Реализация практики безопасного программирования с исправлением уязвимостей SQL Injection, Path Traversal и XSS.

## Ветка

`p06-secure-coding` (от `main`)

## Реализованные исправления

### 1. SQL Injection
- **Файл:** `src/app/sql_injection_fix.py`
- **Исправление:** Параметризованные запросы вместо конкатенации строк
- **Тесты:** `tests/test_sql_injection_fix.py` (7 тестов, включая негативные)

### 2. Path Traversal
- **Файл:** `src/app/path_traversal_fix.py`
- **Исправление:** Валидация путей с проверкой на выход за пределы базовой директории
- **Тесты:** `tests/test_path_traversal_fix.py` (9 тестов, включая негативные)

### 3. XSS (Cross-Site Scripting)
- **Файл:** `src/app/xss_fix.py`
- **Исправление:** Экранирование HTML-символов и валидация опасных паттернов
- **Тесты:** `tests/test_xss_fix.py` (10 тестов, включая негативные)

## Дополнительные модули

- **Валидация:** `src/app/validation.py` - валидация входных данных
- **Логирование:** `src/app/logger.py` - безопасное логирование с маскировкой PII

## Тесты

Всего реализовано **≥47 тестов**:
- SQL Injection: 7 тестов
- Path Traversal: 9 тестов
